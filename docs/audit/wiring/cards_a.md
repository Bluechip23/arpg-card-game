# Wiring audit — cards, slice A

51 cards, `absorb_essence` … `demonic_rage`. Each card's `.tres` description was traced through the real play path (`main.play_selected_card` → `DeckManager.play_card` → the tempo queue → `_resolve_queued_card` → `Card._execute_card` + `main._apply_card_world_effects`, or the instant's trigger site). Every playable card's printed mana and tempo were checked against what that path actually charged.

Test file: `tests/test_wiring_cards_a.gd` (boots `main.tscn` as the dojo; ~1 minute). Checks are cited as `file::check message`; messages that print live numbers are cited up to the number.

## Flagged

- **Whirling Weapon (`composed_reaction`)** — The text says "when you are attacked (melee, ranged or spell)". It fires on any damage you take: Burn/Poison/Choke ticks and self-paid costs (Cultish Wounds' bleed, Communal Donation, Demonic Rage's health price) set it off too. Should it fire only on enemy attacks (e.g. the enemy `attacked_player` signal), or on any damage?
- **Death Vortex (`death_vortex`)** — "After you are hit 5 times": the streak counts every damage instance, DoT ticks and self-inflicted costs included, and never resets except by firing. Should only enemy hits count, and should the streak lapse after some time?
- *(Related to the FIXED Composed Response, `composed_response`.)* When an Overcharge is the only overflow mode, the overflowed card is now discarded (it used to vanish). If the designer instead wants it left on top of the draw pile (what a full hand does with no overflow mode at all), that is a one-line change in `OverflowManager.process_overflow`.

## Notes (shared, not changed here)

- **Glut and Jail count down in whole 5-tempo cycles** (`main._process_glut_countdown`, `DeckManager` jail tick `-= 5`), so Blade Barrage's / Collect Arrows' "Glut 15" lasts 11–15 tempo, and Adimantium Wall's "Jailed for 40 tempo" 36–40, depending on where in the cycle the card resolves. Both are shared keywords, so they were left alone. The tests check that the values are set (15, 40), not when they run out.
- **Mana in card text has two scales.** Sheet cards use design mana (×10 in code): Anticipation "1 mana" = 10, Bloodlust "3 mana" = 30, "Maintain 5M" = 50, Demonic Rage "1 health per mana" = 1 HP per 10. Item-kit texts use raw numbers: Bouncing Shield "10 temporary mana" = 10 (its item text prices the card "55 mana", raw), Defensive Sacrifice "10 mana" = 10, Crops "20 mana" = 20. Each text is consistent with its own convention, so all are CORRECT, but the designer may want one scale.
- **Delays count the resolving tick.** A card's world effect resolves before that tick's `tempo_advanced`, so any timer it starts loses one tempo on that tick. This is the convention for `schedule_delayed_effect` and for every timed debuff (Choke's Silence reads 4 after its tick, the Cupid taunt and fear 4, the tree 3), and Absorb Essence now follows it too.
- Approach's armor is granted in the per-tile pipeline, which the co-op locked batch move skips (`_batch_moving` early-out), so a co-op synchronized move gives no Approach armor.
