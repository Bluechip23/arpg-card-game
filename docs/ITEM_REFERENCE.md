# Item Reference — what the code does

Generated from the item factories in `item_data.gd` and the code that handles each item (`inventory.gd`, `player_stats.gd`, `main.gd`, `buff_manager.gd`, `card.gd`, `item_forge.gd`), not from the description strings. Each entry gives the item's real stats as coded, what the code does with its special effect and item levels, and a **Mismatch** line wherever the code disagrees with the item's own text or a described effect has no code behind it.


**189 items, 28 with something to look at.** The flagged items are listed first, then every item by type and rarity.
