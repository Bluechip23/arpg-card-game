# Passive Reference — what the code does

Generated from the skill-tree definitions in `skill_tree_data.gd` and the code that fires each passive (`progression_triggers.gd`, `passive_scaling.gd`, `passive_cooldowns.gd`, `player_stats.gd`, `main.gd`, the effect managers), not from the description strings. Each entry gives the design text, what the code really does with real numbers and rank scaling, and a **Mismatch** line wherever the code disagrees with the text or a described effect has no code behind it.


**60 passives, 30 with something to look at.** The flagged passives are listed first, then every passive by character in tree order.


## Passives whose code and text disagree

- **Enraged Will** (Brad, level 2): The mana reward is gain_mana(kills*10) — matches the text only if '10 mana' is read in code units (=1 design mana, as the code comment says); if the designer meant 10 design mana it should be 100. · The swing only fires from the damage-taken hook, so if the cooldown expires while Brad is already low it re-triggers on the next hit rather than as soon as it is ready; threshold check is <= (not strictly 'below') and counts temp HP.
- **Point to Prove** (Brad, level 5): The choice is silently not offered when the HP cost would be lethal (current_health <= cost, debuff_manager.gd:88) — an unstated condition, though a sensible one. · The debuff is applied first and only removed after the player confirms (async dialog), so the stun/disarm briefly exists rather than being 'ignored'.
- **Directed Strength** (Brad, level 7): Minor: the check is <= 50% (exactly half counts) and the percent includes temp HP; otherwise matches.
- **The Way of the Plate** (Brad, level 8): '10 mana' is gain_mana(10) = 1 design mana in the ×10 economy; the text and code agree only in code units.
- **Life Steal** (Brad, level 13): Heals at least 1 HP per hit and falls back to the card's listed damage when last_damage_dealt is 0, so fully blocked attacks still life steal.
- **Vines Codependence** (Brad, level 16): Triggers on any direct heal Brad receives, including heals cast by an ally on him (the text 'whenever you heal' is ambiguous on this).
- **Wither** (Cory, level 4): The +1 'charge' is delivered as enemy.apply_debuff(name, 1), but for timer-style debuffs apply_debuff uses max(existing, value) (stun enemy.gd:5082, silenced 5100, root 5146, cursed 5151, narashimha 5161, polymorph 5167), so Wither is a no-op on those and still spends its cooldown. · For 'disarmed' and 'marked', apply_debuff overwrites the timer (disarmed_tempo = value + amp at enemy.gd:5092; marked_tempo = value at 5096), so Wither's +1 actually SHORTENS an existing Disarm/Mark to ~1 tempo instead of adding a charge. · The trigger listens to every enemy debuff_applied signal regardless of source (main.gd:5921), so debuffs applied by allies, traps, or the enemy itself also get the +1 and consume the cooldown, not only debuffs Cory applies.
- **Expel Negativity** (Cory, level 8): The condition is 'while at or below the threshold' on each damage event, not an edge-triggered 'when you drop below': two consecutive hits while low spend both charges, and a single spent charge is never refilled until both are spent and 10 tempo pass (progression_triggers.gd:1553-1558). · Player debuffs without an enemy mapping (Cuffed, Staggered, Drain, Weighted, Hexed, Locked, Clumsy, Brittle, Blind) can never be transferred (PLAYER_DEBUFF_TO_ENEMY_KEY, progression_triggers.gd:1547-1551); if only those are present nothing happens and no charge is spent.
- **Territorial Death** (Cory, level 11): The re-apply is enemy.apply_debuff(key, 1): for max()-timed debuffs (stun, silenced, root, cursed, narashimha, polymorph) it is a no-op, and for Disarm/Marked it overwrites the timer to ~1 tempo; see the Wither note in CLAUDE.md for the buff/debuff rework. · Effects with no apply_debuff key (Taunt, Fear, Tree, Cupid, Wear Down, zone Weaken) are excluded from the random pick.
- **Death as Lifeblood** (Cory, level 14): 'Within 2 squares' is implemented as a Euclidean radius of 2.0 world units, so an enemy 2 squares away diagonally (distance ~2.24-2.83) is not counted while (1,1) and straight-line 2 are.
- **Serial Killer** (Cory, level 16): Invisibility only ends via a targeted ATTACK card (arm_pre_attack_passives, progression_triggers.gd:1316-1319); damaging that enemy with AoE splash, DoTs, gauntlet skills or non-attack cards does not reveal the player, unlike 'until you attack them'.
- **Regrowth** (Cory, level 18): The cooldown is committed before any draw happens (progression_triggers.gd:1664), so when Cuffed or the draw/discard piles are empty the passive draws 0 cards yet still goes on its 25-11 tempo cooldown. · It fires on ANY hand_updated with an empty hand, not only on 'emptying your hand' by play: erase ticks, jail/discard, add_card_to_hand paths and restore_deck_state on load (deck_manager.gd:189, 977, 1004, 1147, 1206) all qualify, and each hand_updated while the hand stays empty re-checks the trigger.
- **Whispers of the Flock** (Jeremy, level 8): Other summon kinds (Frankensteins, worms, skeletons, spirit bows, clones, the penguin) have no mark fields yet, so a mark played on them does nothing.
- **Mana Surge** (Jeremy, level 13): docs/CHARACTERS.md:62 describes the trigger as 'spending 10 mana inside 5 tempo' while the tree text and code use 100 (code counts displayed mana units), so the two design texts disagree; the code matches the tree text. · Spending is recorded when each card RESOLVES (main.gd:8735), not when it is cast, so wind-up delays shift what falls inside the 5-tempo window.
- **Blood Libation** (Jeremy, level 16): A stack is granted on every take_damage call, including hits fully absorbed by armor/temp HP (no early return between player_stats.gd:1709 and 1897), so 'takes damage' effectively means 'is hit'.
- **Stimulant** (Ryan, level 4): The trigger keys off heal_amount > 0, so it also fires (and spends the cooldown) when Poisoned Blood flips the Pocket heal into a poison outcome and nobody is actually healed (compare the flip check at progression_triggers.gd:674-676).
- **From the Hip** (Ryan, level 7): The mana table plateaus at ranks 12-13 (both -65m) by design.
- **Mad Scientist** (Ryan, level 16): Poison Bomb (the only Pocket poison card besides Poisoned Blood) resolves against mouse_pos, not `target` (main.gd:11241-11249), so the Utility->Poison and Defense->Poison riders only land if a single enemy happened to be passed as target, not on the enemies the bomb actually poisoned. · The Poisoned-Blood flip (progression_triggers.gd:674-676) turns a self/ally heal into a poison outcome whose target is a Player, which has no apply_debuff method and is not an Enemy, so both poison riders silently do nothing for flipped heals. · Utility->Heal regen is given a hard-coded 15-tempo duration (progression_triggers.gd:685) that the description does not state. · 'Potion cards' is implemented as any Pocket-labelled card (dagger_throw, quick_shot, draw, heal, etc. via CARD_SLOT_LABELS), not only potions; in practice only heal/poison Pocket cards produce an outcome.
- **Eye Scrape** (Ryan, level 18): Crits are counted once per resolved card play (main.gd:8749-8752 uses a single last_crit_hit flag), so a multi-hit card that crits several times advances the 'every Nth critical strike' counter by only 1.
- **Deadly** (Stephen, level 2): Only Attack-type cards trigger it (main.gd:8736); basic attacks and other damaging cards get neither the damage nor the crit bonus even against an isolated target. · 'Within 2 spaces' is coded as 3D Euclidean distance <= 2.0 (progression_triggers.gd:1283), so a diagonal ally at (2,1) or an ally on different elevation is treated as not within 2 spaces.
- **Clean Exchange** (Stephen, level 3): 'Offensive card' is coded as card_type == ATTACK (progression_triggers.gd:722-723), not Card.is_offensive() (card.gd:2731), so drawing/having played a damaging Utility or spell card never triggers the exchange.
- **Eagle Eye** (Stephen, level 4): The is_offensive() check is unreachable for non-Attack cards: the Stephen on_attack hook only runs when card.card_type == ATTACK (main.gd:8736-8739), so ranged offensive Utility/spell cards described by 'ranged offensive cards' get no bonus. · Range counted is base 5 + range_modifier (progression_triggers.gd:1219), ignoring in-play range bonuses (Scouted, Tighten String, sphere Range +X, helm), so the bonus does not follow the card's actual range.
- **Patience is a Virtue** (Stephen, level 5): The Glut is only halved when the nearest enemy is within melee range (progression_triggers.gd:1404-1411); with no melee-range enemy neither the damage nor the halving happens, whereas the text implies the halving always follows. · Only the nearest enemy is considered; if it is at range 3+ no other melee-range enemy is checked (progression_triggers.gd:1404-1407).
- **Exposed Blind Spot** (Stephen, level 8): 'Melee attack' is judged by attacker adjacency (<=1.5 tiles), not attack type: an adjacent ranged/shoot attack triggers it and a reach-2 melee hit does not (progression_triggers.gd:1359, 1011-1015). · Repeated hits overwrite rather than accumulate the bonus (assignment at progression_triggers.gd:1366), and the fractional per-card value is rounded to a whole percent, so e.g. 1 card at rank 2 gives 1% not 1.25%.
- **Scouted** (Stephen, level 9): 'Hits' are counted per Attack-card resolution (main.gd:8736-8739), not landed hits: a blocked/missed attack still counts and basic attacks never count. · The auto-crit is a 1-charge Enlightened buff consumed by the next crit roll (buff_manager.gd:530-534), so a basic attack can spend the auto-crit while the +range and +crit-damage stay armed for the following card, splitting the described single 'next attack' bonus.
- **Swing for the Fences** (Stephen, level 11): Text says 'Cards' but only Attack-type cards get the bonus (main.gd:8736); a >4-tempo damaging Utility/spell card does not.
- **Skilled Momentum** (Stephen, level 13): 'Played twice' is implemented as re-dealing the card's last damage number to the target (progression_triggers.gd:1261-1264), not a second execution: no second crit roll, debuffs, AoE, draw, or other card effects. · If the card's damage was 0 (missed/non-damaging attack) the double strike still deals effective base damage (progression_triggers.gd:1263).
- **Lethal Resourcefulness** (Stephen, level 14): The 'free basic attack' requires the nearest enemy to be within 2 tiles (progression_triggers.gd:1385-1387), a melee-range condition not in the text; a bow-wielding Stephen at range gets nothing. · It is not a real basic attack: it bypasses the basic-attack pipeline (no crit roll, no DEX attack-speed registration, no conditional ranged reach), just flat effective physical damage of 0 base (progression_triggers.gd:1390-1391).
- **Laced Arrow** (Stephen, level 16): The chance table is not a smooth 50→100 ramp: +3 per rank to 89% at rank 14, then a jump to 100% at rank 15 (passive_scaling.gd:234). · It triggers on any burn/cold/shock landing on an enemy, including rider re-applications (Harnessed Sun at main.gd:5966-5970, Wither at 5988-5996) and non-player sources, so a single application can roll Laced Arrow more than once.
- **Dominate** (Stephen, level 18): Stale duplicate text at scripts/character/character_data.gd:198 still says '0m/0t basic attack card' with no Strengthen, contradicting the tree description and the code (30m/0t + Strengthen).
