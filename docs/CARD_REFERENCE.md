# Card Reference — what the code does

Generated from the card factories, `Card.execute`, and the handling in `main.gd`, `deck_manager.gd` and the effect managers, not from the description strings. Each entry gives the card's real numbers and behaviour as implemented, and a **Mismatch** line wherever the code disagrees with the card's own description text or with the design sheet's type / target column, or where a described effect has no code behind it.

Costs are the code's raw numbers (the sheet writes mana in tens). Range is the base 5 plus the card's modifier; melee cards have none. Slots are the sheet's slot labels; **Engrave** marks a card that exists only inside an item slot.


**240 cards, 32 with something to look at.** The flagged cards are listed first, then every card by type.


## Cards whose code and text disagree

- **A Snowball's Chance** (`snowballs_chance`): 'Searing fire' is flavour only: the fire line deals untyped/physical damage (take_damage(dmg, true) without DamageTypes.FIRE) and no Burn is applied.
- **Absorb Essence** (`absorb_essence`): Sheet type 'spell, Offensive' agrees (school SPELL, keywords spell/offensive).
- **Attack** (`slash`): Minor: when it resolves as ranged the card costs +1 tempo (CONDITIONAL_RANGED_TEMPO_PENALTY), which the description does not mention.
- **Balistic Arrow** (`balistic_arrow`): Minor: unlike normal attacks the line damage skips the crit roll and Strengthen consumption (_compute_attack_damage only scales by STR).
- **Bouncing Shield** (`bouncing_shield`): Minor: the 5 damage per bounce is flat (bypasses STR scaling, Strengthen and crit) unlike the card's damage=5 field suggests; description matches numerically. · Minor: temp-mana duration is 20 tempo (not 15) when the granting shield is item_level >= 2 — description always says 15.
- **Choke** (`choke`): Description does not state the card is ranged 5 (sheet 'spell, Offensive' is silent on range; code is ranged 5).
- **Communal Donation** (`communal_donation`): Sheet 'ranged for heal is infinite' agrees (range_modifier = INFINITE_RANGE).
- **Composed Response** (`composed_response`): Minor: the reaction fires on 'on_damage_taken' (the player actually loses HP/armor), so an attack that deals no damage does not set it off.
- **Crack of Mintaka** (`crack_of_mintaka`): If the player discards fewer cards than the distance the damage is lost but the discards still happen — description implies the enemy must be 'within that many squares' so this is consistent, just harsh.
- **Element Pollination** (`element_pollination`): Minor wording: 'Shock freezes at 5 stacks like Cold' is implemented as a 5-tempo STUN (is_stunned), whereas Cold at 5 stacks sets is_frozen; functionally similar but a different status.
- **Enchantment: Attack** (`enchantment_attack`): Minor: the +3 applies to everything that goes through the effective-damage pipeline (basic attacks, INT-scaled ticks, etc.), not only to 'cards'.
- **Energy Ball** (`energy_ball`): description says 'Deal X damage where X = total damage done by Absorb Essence', but the code then runs X through get_effective_spell_damage so INT/spell bonuses and crits scale it above X (minor).
- **Exacerbate Wounds** (`exacerbate_wounds`): Sheet says 'Attack, Melee' but the card is Conditional: ranged (base 5, +1 tempo) when holding a bow (deck_manager.gd:63).
- **Friendship** (`friendship`): damage split is 'partner takes floor(half), you keep the rest' and only when amount > 1 — 1-damage hits are not split (minor).
- **God of Thunder** (`god_of_thunder`): Damage is exactly 1 per shock stack absorbed and is not scaled by INT/spell damage — 'massive bolt' is only as big as the shock present; if no enemy has shock the card does nothing (informational).
- **Hard Helmet** (`hard_helmet`): Minor: description says 'closest enemy' but the site effect hits the played utility card's enemy target first (falls back to the nearest enemy only when the utility had no enemy target).
- **Healthy Bliss** (`healthy_bliss`): Minor: description says 'heal all allies for 10' but the heal is stat-scaled via get_effective_heal_amount (INT + healing bonuses), so it is usually more than 10.
- **Hope This Works** (`hope_this_works`): Minor: 'provide STR' is implemented as Strengthen +2 damage for 3 attacks, not a STR stat buff.
- **Lethal Recall** (`lethal_recall`): minor: reactions armed via _arm_lethal_recall store a null target, so instants whose trigger site did not go through _fire_instant_site_effect (e.g. Close is Favored sets _last_played_target manually, Spider Senses/Cover have no site effect) replay with target=null; for Close is Favored the target is set at its site, others are self-only so no real gap.
- **Life Swap** (`life_swap`): Description does not mention that the swap can never drop HP below 1 or exceed max pools (code clamps both).
- **Poison Bomb** (`poison_bomb`): range 6 is not enforced: point-target cards play via play_selected_card(player) with no distance check (only Blink is range-checked) and the world effect uses the raw click position, so the cloud can be placed anywhere.
- **Push** (`push`): Minor: description says 'a unit' but target_types is ['enemy'] — allies cannot be pushed.
- **Rain of Arrows** (`rain_of_arrows`): If the card were ever played from hand it does nothing (no execute branch, no world-effect branch) — NOT IMPLEMENTED as a playable card; only the shield Overdraw hardcode (flat 10, radius 3) exists.
- **Shuriken** (`shuriken`): description says 'Deal 3 damage' — code deals _card_player_damage (3 plus STR and other flat bonuses), not a flat 3 (minor).
- **Sprinkle Bomb** (`sprinkle_bomb`): Minor: AOE damage skips crit and Strengthen (only stat-scaled).
- **The Nibelung Curse** (`the_nibelung_curse`): Minor: execute() has no branch for this id (hits the default 'Unknown card' print); harmless because all effect lives in main._apply_card_world_effects.
- **Tighten String** (`tighten_string`): A shot returned to hand because its target died also spends a charge.
- **Tricks of Alberich** (`tricks_of_alberich`): Minor: execute() has no branch for this id (default print only); effect is fully in main. · Minor: the Regen buff lasts 15 tempo (not tied to the taunt's 5); description gives no duration.
- **Understanding** (`understanding`): Minor: the 100% Enlightened charge is spent by the next BuffManager.roll_crit, so damaging cards whose path never rolls crit (e.g. Exposed Artery, Shield Slam, God of Thunder, Balistic Arrow, flat item AOEs) neither crit nor spend it — it waits for the next card that does roll.
- **Vines** (`vines`): Description says damage is dealt 'per turn the enemy is held still'; code deals all 3 ticks unconditionally (rooted enemies cannot move anyway, but the ticks do not check the root state, e.g. if root is cleansed) — minor. · Sheet lists 'ranged' twice/misspelled ('raned 5'); code range 5 agrees.
- **What's the Worst?** (`worst_that_could_happen`): Minor: the +15 rider is flat (not STR-scaled, no crit).
- **Wrath of the Sea** (`wrath_of_the_sea`): description says enemies are 'shoved to its edge' — code applies a fixed knockback of 2 tiles away from the landing point, which does not necessarily land them on the edge of the 4x4 burst (minor). · no range is enforced on the blink point (point-target cards skip the range check; only Blink is range-checked).
